## 통신 패턴
- **U7 ↔ U6**: Tauri `command`(요청/응답) + `event`(상태 푸시). 직렬화 경계에서 입력 검증(SECURITY-05).
- **U6 ↔ U2/U3/U4/U5**: 포트 트레이트 호출(DI). U6은 구체 어댑터 타입을 조립 시점에만 앎.
- **U*/U6 ↔ U1**: 함수/타입 직접 호출(순수).

## 권장 개발/설계 순서 (기반 우선 — Per-Unit Loop)
```
1) U1 vc-core        (모델·포트·순수 로직; 단위/PBT 기반)
2) U2 vc-store       (원자적 저장·마이그레이션; PBT-02)
3) U3 vc-os-macos    ┐ (플랫폼 어댑터; 모의로 U6 통합 테스트 병행 가능)
4) U4 vc-os-windows  ┘
5) U5 vc-sessions    (Claude Code provider; PBT-03)
6) U6 vc-app         (서비스+브리지 조립; 통합)
7) U7 frontend       (대시보드 UI; E2E)
```
- U3/U4는 U1 완료 후 병렬 가능. U6은 하위 단위 인터페이스 확정 후 착수하되, 모의 포트로 선행 통합 테스트 가능.
