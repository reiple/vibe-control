# 사용자 페르소나 (Personas)

단계: INCEPTION — User Stories
참조: `requirements.md`, `story-generation-plan.md`

---

## P1. 지호 — 멀티프로젝트 개발자 (Developer)

- **역할/맥락**: 여러 저장소·서비스를 동시에 진행하는 소프트웨어 개발자. macOS와 Windows를 오가며 작업.
- **주로 쓰는 도구**: 코드 편집기(VS Code 등), 터미널, Chrome/Safari/Edge, 파일 탐색기/파인더, 메신저.
- **동기 (Goals)**:
  - 프로젝트를 전환할 때마다 편집기·터미널·브라우저 탭·폴더를 다시 여는 반복 작업을 없애고 싶다.
  - "정확히 그 창/그 탭"으로 즉시 복귀하고 싶다(비슷한 창이 많음).
- **불만/페인 (Pains)**:
  - 같은 앱의 창이 여러 개라 무엇이 어떤 프로젝트용인지 헷갈린다.
  - 창을 닫아버리면 어떤 폴더/URL이었는지 기억나지 않는다.
- **핵심 니즈**: 창·탭·폴더의 정확한 식별과 복원, 한 번에 전체 컨텍스트 활성화, 크로스플랫폼 동작.
- **관련 에픽**: EPIC-1~11 전반, 특히 EPIC-3/4/5/9/10.

---

## P2. 세아 — 프로덕트 디자이너 (Designer)

- **역할/맥락**: 여러 제품의 디자인을 병행. 브라우저 기반 디자인 툴·레퍼런스 탭·에셋 폴더를 반복적으로 구성.
- **주로 쓰는 도구**: 브라우저(다수 탭), 파일 관리자(에셋 폴더), 디자인/문서 앱, 메신저.
- **동기 (Goals)**:
  - 프로젝트별 레퍼런스 탭 묶음과 에셋 폴더를 저장해두고 한 번에 복원하고 싶다.
  - 기술 용어 없는 단순하고 시각적인 대시보드를 원한다.
- **불만/페인 (Pains)**:
  - 같은 주소를 연 탭이 여러 개라 목록에서 구분이 안 된다.
  - 창 위치보다 "무엇을 열어두었는가"의 복원이 중요한데 도구가 과하게 복잡하다.
- **핵심 니즈**: 브라우저 탭·폴더 중심 저장/복원, 명확한 아이콘·상태 표시, 조절 가능한 레이아웃(패널/카드).
- **관련 에픽**: EPIC-2/3/7/8/9, 부분적으로 EPIC-4/5.

## P3. 루카 — AI 협업 개발자 (AI-assisted Developer)

- **역할/맥락**: 코딩 에이전트 CLI(우선 **Claude Code**, 이후 Codex·OpenCode)를 여러 프로젝트에서 병행 실행. 각 세션이 질문을 던지고 답을 기다리는 경우가 많다.
- **주로 쓰는 도구**: 터미널에서 실행되는 코딩 에이전트 세션, 코드 편집기, 브라우저.
- **동기 (Goals)**:
  - 여러 코딩 세션 중 "지금 내 답변을 기다리는 세션"을 한눈에 파악하고 싶다.
  - 각 세션의 마지막 질문과 전체 대화를 앱에서 바로 확인하고 싶다.
  - 세션을 작업 묶음의 일부로 저장해 프로젝트 컨텍스트와 함께 복원하고 싶다.
- **불만/페인 (Pains)**:
  - 터미널 창이 많아 어떤 세션이 대기 중인지 놓친다.
  - 세션 내용을 확인하려 창을 일일이 뒤져야 한다.
- **핵심 니즈**: 코딩 세션의 대화·마지막 질문·답변 완료여부 표시(읽기 전용), 자동 갱신, 확장 가능한 도구 지원.
- **관련 에픽**: EPIC-12(핵심), EPIC-1/3/4/7과 연계.
